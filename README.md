# Beer Price Calculator

I need a basic app that calculates total price.
The price is calculated by:
Bear*19 + shot*9
So for example: 2 bears and a shot equals to 47.
Display it like this: two squares on next to each other, one to type the bear price and one for the shit price.
Under that display in big the total price
